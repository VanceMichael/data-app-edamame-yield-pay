# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## raw_lots

采摘与预冷影响可比保存时长。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 原料批 |
| `grade` | string | 老嫩等级 |
| `harvest_minute` | integer | 采摘分钟 |
| `chilled_minute` | integer | 预冷分钟 |
| `processable_until` | integer | 可加工截止 |

## issues

发料承诺和实际交接；重量千克。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 发料 |
| `lot` | string | 原料批 |
| `worker` | string | 加工人 |
| `kg` | number | 交接重量 |
| `minute` | integer | 实际分钟 |
| `promised_kg` | number | 已通知下期量 |
| `worked_hours` | number | 已确认工时，负一表示未提供 |

显式引用：`lot` → `raw_lots.id`。

## returns

一份回料只归一份发料；同发料可分次。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 回料 |
| `issue` | string | 发料 |
| `bag` | string | 送检袋 |
| `kg` | number | 成品千克 |
| `minute` | integer | 实际分钟 |

显式引用：`issue` → `issues.id`；`bag` → `bags.id`。

## bags

共同袋封样决定后续能否归因。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 袋 |
| `seal` | string | 封样状态 |

## samples

混袋检验不是各发料完整质量。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 样本 |
| `bag` | string | 袋 |
| `design` | string | 计划随机或定向 |
| `prob` | number | 入样概率 |
| `bad_fraction` | number | 坏豆比例 |
| `known_minute` | integer | 知悉分钟 |

显式引用：`bag` → `bags.id`。

## retests

复检结论只陈述事实及适用范围。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 复检 |
| `lot` | string | 原料批 |
| `bag` | string | 袋 |
| `finding` | string | 事实 |
| `known_minute` | integer | 收到分钟 |

显式引用：`lot` → `raw_lots.id`；`bag` → `bags.id`。

## pay_rules

历史生效协议，分与比例。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 协议 |
| `effective_minute` | integer | 起效 |
| `unit_cents_per_kg` | integer | 每千克工钱 |
| `deferred_fraction` | number | 质量递延比例 |
| `minimum_uncontested_fraction` | number | 可独立支付比例 |

## payments

实际已付，不覆盖。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 支付 |
| `return_id` | string | 回料 |
| `amount_cents` | integer | 金额 |
| `minute` | integer | 支付分钟 |

显式引用：`return_id` → `returns.id`。

## inspection_capacity

下期抽检可用窗口。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 能力 |
| `start` | integer | 起分钟 |
| `end` | integer | 止分钟 |
| `bags` | integer | 袋数 |
